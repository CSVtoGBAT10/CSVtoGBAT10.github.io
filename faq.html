FAQ

Is this open source?

Yes. Every importer is a plain HTML/CSS/JS file — nothing is compiled, bundled, or obfuscated. You can view the source of any page directly in your browser.

Is my data uploaded anywhere?

No. The CSV you select never leaves your browser. Parsing and transformation happen entirely client-side in JavaScript; there is no server component and nothing is transmitted.

Is it safe to use with financial data?

Since nothing is sent anywhere, using these tools carries the same exposure as opening the CSV in a text editor. You can verify this yourself by reading the source or checking your browser's network tab while a transform runs.
