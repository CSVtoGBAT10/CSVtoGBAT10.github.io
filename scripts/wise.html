Wise to GBAT10

Convert a Wise account statement CSV export into a Tripletex GBAT10 import file.

About Wise

Wise account statements list transactions with amounts, descriptions, and payee names, but not in a format Tripletex can import directly. This tool converts a Wise CSV statement into GBAT10, letting you assign a GL account and, where relevant, a customer or supplier account number to each counterparty. Export the statement for one currency at a time — a file containing multiple currencies will produce incorrect amounts.

  1. In Wise, download your account statement as a CSV, in English (UK), for one currency at a time.
  2. Upload the CSV below and set the account for each counterparty when prompted.
  3. Download the resulting GBAT10 file and upload it to Tripletex.
