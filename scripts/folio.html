Folio to GBAT10

Convert a Folio card transaction CSV export into a Tripletex GBAT10 import file.

About Folio

Folio is a portal for managing card transactions in corporations. It supports various integrations and exports, none of which are GBAT10 or otherwise readily available for Tripletex imports. Our simple tool covers this existing gap in functionality.

  1. In the Folio dashboard, export card transactions as a CSV, along with any voucher receipts.
  2. Upload the CSV below and download the resulting GBAT10 file.
  3. Upload the GBAT10 file to Tripletex, then attach the voucher receipts to each imported transaction.
