About

A small collection of client-side tools for converting external CSV exports into Tripletex's GBAT10 voucher import format.

Why this exists

Tripletex's GBAT10 format is exact but rigid: fixed columns, semicolon-delimited, balanced debit/credit postings per voucher. Most external systems don't export data in this shape, so every source needs a small, purpose-built transform. Each tool on the overview page handles one source system.

How it works

Each importer reads a CSV you select, restructures it into GBAT10 rows in memory, and offers the result as a download. No server is involved at any point — the transform runs in JavaScript, in your browser tab.
